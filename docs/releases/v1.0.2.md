# VoiceTranslation v1.0.2

**此安装包尚未完成 Apple Developer ID 签名和 Apple 公证。** 使用临时签名，macOS 可能阻止首次打开；不能宣称已通过苹果安全认证。请先阅读[安装说明](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.2/docs/guides/INSTALLATION.md)，不要关闭系统安全保护。

## 本版修复

- 耳机切换、断连或重连后，跟随系统当前选择的麦克风恢复收音。
- 暂时无法收音时继续尝试；设备接回后尽快重新连接，不再因几次失败就忘记正在录音。
- 修复 AirPods 切换通话模式时可能导致退出的问题；等待声音设备时保持窗口可操作。
- 已废弃的收音过程不再把声音送入新的识别过程，也不再误报已经恢复。实际收到声音数据后才显示收音就绪。
- 点击停止后不会因设备变化自行录音；系统音频失败仍不会自动打开麦克风。

## 实测范围

2026-11-16，在一台 Apple Silicon Mac、macOS 27.2.1 上使用 AirPods 4：

- 实际切换内置麦克风和耳机、断开蓝牙后恢复内置麦克风、重连耳机，均核对了变化后新收到的原文和完成的译文，全程未重新点击开始。
- 用户将耳机切到手机播放声音，再切回 Mac；新说的会议时间正确译出。
- 导出文件保存成功，23 组原文与译文逐条匹配本机保存内容；退出重开后内容、翻译配置和前文设置保留，录音未自行启动。旧对话内容仍保留。
- 164 项自动检查通过，另 1 项需手动开启的真实服务检查跳过；公开源码保护检查通过。

这是针对设备恢复的验收，不是识别准确率承诺。实测中仍有 order/author、boxes/bucks 和数字听错，后续清晰句子识别、翻译通过；重要内容请复核或修改原文。没有重跑半小时连续讲话、睡眠唤醒、Intel 或全部旧系统实机验收，也未重新实录系统音频。

## 下载和更新

下方 Assets 的 **VoiceTranslation.dmg** 为推荐安装包，**VoiceTranslation.app.zip** 为备用包，**SHA256SUMS.txt** 用于校验。版本 1.0.2，构建 8，Apple Silicon 与 Intel 通用，最低 macOS 13。

**本次发布的安装包就是本机实际验收的同一份文件。** 源码另由 GitHub Actions 独立检查和构建；发布时使用本机已验收的通用安装包，不把另一份构建冒充为已实测文件。

先停止录音并正常退出旧版，再替换“应用程序”里的应用；不需要删除历史或钥匙串。更新后 macOS 可能再次要求语音识别、麦克风、系统音频或原密钥访问确认。公开包不含服务密钥和本机对话，翻译需要自己的服务配置，费用按所选服务收取。

## English

**NOT Apple Developer ID signed or notarized.** Uses ad-hoc signing; macOS may block launch. Do not disable system protections.

v1.0.2 improves recovery when the default microphone changes, headphones disconnect or reconnect, and AirPods change audio profiles. Capture keeps retrying temporary failures until stopped or a permission failure occurs. Retired capture cannot feed a replacement recognition request. An explicit stop prevents automatic restart; system-audio failures still never activate the microphone.

AirPods 4 switching, physical Bluetooth disconnection/reconnection, and a user-operated phone-to-Mac handoff were tested with fresh speech and completed translations on one Apple Silicon Mac. Export and reopening preserved all 23 original/translation pairs. 164 automated checks passed; one opt-in service check was skipped. Recognition still made word and number mistakes; this is recovery acceptance, not a recognition-accuracy guarantee or universal hardware certification. Long-duration speech, sleep/wake, Intel, all older macOS versions and fresh system-audio recording were not repeated in this release test.

Release assets are the exact locally tested universal 1.0.2 (8) packages. GitHub Actions independently checks and builds the same source; its separately built assets are replaced in the unpublished draft with these tested packages before publication. Minimum macOS 13. Stop and quit before updating, keep your history/Keychain, and approve expected permission prompts as needed.

# VoiceTranslation v1.0.3

**尚未完成 Apple Developer ID 签名和 Apple 公证。** 安装包使用临时签名，macOS 可能阻止首次打开；不能宣称通过苹果安全认证。先阅读[安装说明](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.3/docs/guides/INSTALLATION.md)，不要关闭系统安全保护。

## 本版改进

- 重点核对数字、金额、日期、时间、单位以及指定人名和专业词。可疑译文去掉前文再试一次，仍有疑点就保留原文并显示待核对，重开后不会无限重试。
- 新增本场名单，优先于通用术语；开启历史后随场次保存，重开保留，新场次重新开始。
- 修改简短人名或专业词时可明确选择记住。以后辅助识别并提供纠正建议，点击采用后才改原文、更新译文；后续识别仍不能覆盖手动修改。数字修改不会成为通用替换规则。
- 修正符号金额、同译名别称及中文紧贴英文专业词导致的误拦，补充保存、费用和隐私说明。

## 实测与限制

同一台 Apple Silicon Mac 上，旧版和最终新版回放同一份约 118 秒真人录音，以及单独标明的约 57 秒合成标准读音补充。使用相同有效词表、服务和前文设置，通过本机虚拟声音设备进入真实识别和翻译流程，未注入识别文字。最终真人 12 段、合成补充 8 段均译完。

金额、箱数、日期、负温度、距离及未说明币种的样例保留事实；姓名列表被服务补入动作时，实际拦为待核对。手动把 15 改成 50 后，继续播放新的 15 未覆盖旧段，也没有把新段改成 50。纠错建议确认后才修改；未完成的时间未借用前文补全。导出 12 组内容逐条一致，退出重开保留名单、记忆和手动原文，未自行录音。原有 18 场、294 段记录保持不变。180 项自动检查通过、1 项跳过。

**原始听写仍会听错，不能声称人名和数字已全部准确。** 读者有部分单词不熟悉；同一声音的识别也会波动，fifty 在标准补充中仍被听为 fifteen。这轮未重新验收物理麦克风、系统音频捕获、耳机恢复、睡眠唤醒、半小时录音、Intel 或所有旧系统。有限核对也不能覆盖所有语义问题。详见[完整验证边界](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.3/docs/VALIDATION.md)。

## English

**NOT Apple Developer ID signed or notarized.** This ad-hoc signed universal 1.0.3 (11) package requires macOS 13 or later. Do not disable system security protections.

Adds conservative fact/term validation with one context-free retry and a persistent review state, session vocabulary, and explicitly saved short-word corrections with confirmation-only suggestions. Manual originals remain authoritative; numeric edits never create reusable replacement rules. Extra provider calls may incur charges.

The exact final installed binary replayed identical 118-second human and separately labelled 57-second synthetic recordings through an existing virtual audio input and the real recognition/translation services. Final output: 12 human rows and 8 synthetic rows completed. Manual edits, suggestions, incomplete-time handling, native export and reopening were exercised; all 12 exported pairs matched. Existing 18 conversations/294 rows were preserved. 180 automated checks passed; one opt-in check was skipped.

This is not a recognition-accuracy improvement claim. Names and numbers still get misheard; the human reader reported unfamiliar words, and fifty was still heard as fifteen in the synthetic group. Physical microphone/system-audio capture, AirPods, sleep/wake, long-duration use, Intel and all older systems were not revalidated this round. Conservative checks cannot prove all semantic facts correct.

Assets are the exact locally tested files. CI independently validates/builds the source; its draft assets are replaced with those tested files before publication. No credentials, private recordings or local conversations are included. See the linked installation, usage, privacy and validation documents.

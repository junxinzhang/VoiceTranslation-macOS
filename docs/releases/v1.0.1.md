# VoiceTranslation v1.0.1

**此安装包尚未完成 Apple Developer ID 签名和 Apple 公证。** 使用临时签名，macOS 可能阻止首次打开；不能宣称已通过苹果安全认证。请先阅读[安装说明](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.1/docs/guides/INSTALLATION.md)，不要关闭系统安全保护。

## 本版修复

- 系统音频故障时只重试原来源或停止，不会自行打开麦克风。
- 删除历史会同步清除整场保存和恢复副本，清空全部历史也会清空当前窗口；后续保存、重开或迟到的译文不会恢复已删除内容。
- 密钥成功迁入钥匙串后，会清理旧配置中的遗留副本，保留其他设置。迁移或清理失败会明确提示。

建议 v1.0.0 用户升级。先停止录音、正常退出旧版，再替换应用。更新后留意系统权限和密钥保存提示；不需要删除自己的历史或钥匙串。导出文件、设备备份和私有仓库旧历史不属于应用内删除范围。

## 下载和使用

下方 Assets 的 **VoiceTranslation.dmg** 为推荐安装包，**VoiceTranslation.app.zip** 为备用包，**SHA256SUMS.txt** 用于核对下载完整性。Apple Silicon 与 Intel 通用，最低 macOS 13；未逐一实测所有系统和硬件组合。

打开 DMG，把应用拖入“应用程序”，推出镜像后打开。允许所选来源需要的权限，在设置里填写自己的服务密钥、地址和模型，再开始翻译。重要姓名、金额和日期仍需复核。

## 本版验证

使用实际运行的应用组件注入系统音频失败，检查麦克风访问次数为零且声音来源不变；使用临时目录检查删除、重开、旧保存请求、迟到翻译和继续识别；用系统钥匙串及虚构密钥验证迁移与清理，并覆盖迁移失败和保留新密钥的情况。未以真实会议内容或真实服务密钥测试泄露。

## English

**NOT Apple Developer ID signed or notarized.** Uses ad-hoc signing; macOS may block launch. Read the installation guide and do not disable system protections.

This security update prevents automatic microphone fallback, removes deleted history from conversation/resume copies and stale work, and cleans legacy credential fields after verified Keychain migration. Upgrade from v1.0.0 by stopping capture and quitting before replacing the app. Exports, backups and private repository history must be managed separately.

Fault-injection tests exercise actual capture startup and check zero microphone access. Disk persistence tests cover deletion, restart, late replies and continued recognition. Synthetic credentials exercise real OS Keychain cleanup; no real service credentials or private meetings are submitted for testing.

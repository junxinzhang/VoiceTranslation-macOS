## 下载与安装

- **VoiceTranslation.dmg**：推荐。打开镜像，把应用拖入“应用程序”，推出镜像，再从“应用程序”打开。
- **VoiceTranslation.app.zip**：备用。解压后把应用移入“应用程序”。
- **SHA256SUMS.txt**：两个安装包的校验值。只用于核对文件完整性，不能替代苹果安全检查。

下载入口在本页下方 Assets。两个包均包含 Apple Silicon / Intel 架构，最低 macOS 13；Intel 及所有旧系统版本尚未逐一实机验证。

完整的[安装与安全提示](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.0/docs/guides/INSTALLATION.md)包含文件校验、系统拦截处理和首次授权步骤。不要关闭系统安全保护，也不要批量清除文件的隔离属性。对于“将损坏电脑”“已损坏”等提示，应停止安装并核实来源，不能仅按普通首次打开提示处理。

## 首次使用

1. 根据系统提示允许语音识别、麦克风及所选声音来源需要的系统音频权限。
2. 在“设置”填写自己的 OpenAI 或兼容服务密钥；自定义服务还需完整接口地址与模型名。公开安装包没有密钥和免费额度。
3. 选择英中方向和麦克风 / 系统音频，开始翻译；等状态显示已准备好再讲话或播放声音。
4. 按需保存术语、修改听错的原文；待译数量归零后导出。系统识别可能使用 Apple 在线服务，原文及相关术语/前文会发往所选翻译服务，见[隐私说明](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.0/PRIVACY.md)。

## 本版内容与验证

包含实时英中双向翻译、术语与前文、原文纠正、自动补译、整场保存、重开恢复及文字导出。录音与翻译逻辑沿用已实测的公开源码，发布整理没有修改这些功能。

已实测内置麦克风、静音系统音频、连续快讲、导出保存及退出重开。测试范围和已知限制见[实测记录](https://github.com/junxinzhang/VoiceTranslation-macOS/blob/v1.0.0/docs/VALIDATION.md)。少见词（例如 Kubernetes）、口音、噪声、多人同时讲话仍可能造成听错；重要的人名、金额和日期请复核。

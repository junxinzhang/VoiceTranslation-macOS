# 公开分发检查

- [ ] 源码通过 `python3 scripts/check_public_source.py`，并审阅新增文件及历史。
- [ ] 不把真实密钥注入应用、CI 安装包或公开截图。
- [ ] 不包含本机设置、钥匙串导出、对话、音频、备份和测试产物。
- [ ] 在独立源码目录从零构建，不依赖本机忽略文件。
- [ ] `bash scripts/test.sh` 通过；列明跳过项，不能算作通过。
- [ ] 新安装、填写配置、授权、麦克风、系统音频、术语、编辑、恢复、导出流程实际验证。
- [ ] 真正播放或录入新声音来验证恢复，不只观察状态。
- [ ] 核对 `LICENSE`、`PRIVACY.md`、`SECURITY.md`、中英文 README。
- [ ] 说明最低系统、架构、签名和是否公证。默认临时签名包不应描述为已公证。
- [ ] 用发布者自己的 Developer ID 签名和公证（若提供经过公证的版本），不要求用户关闭系统保护。
- [ ] 校验下载包可挂载、应用可读取，并发布校验值。
- [ ] 发布前检查 Git 历史是否曾带过真实密钥；需要时使用干净源码快照开启公开仓库，保留原历史在私有位置。删除当前文件不能清理旧提交。

不要在含本机测试备份的工作目录直接打包整个目录。`build-local/` 只用于本地构建和验收，不作为公开源码。开源不等于自动上传或发布安装包；具体公开目的地、标签和说明仍需核对。

# 使用说明

尚未安装时，先看[下载、安装与安全提示](INSTALLATION.md)。当前安装包尚未完成 Apple Developer ID 签名和公证。

## 开始前

1. 在“设置”选择服务，填写自己的密钥。自定义服务需要完整的 Chat Completions 地址（通常以 `/v1/chat/completions` 结尾）及支持的模型名。
2. 点击测试连接。翻译是外部服务调用，可能消耗你的额度。
3. 选择 English → 中文，或反向中文 → English。
4. 选“麦克风”听现场讲话，选“系统音频”听电脑播放内容。系统音频失败不会改录麦克风；如确实需要，请自行选择麦克风后开始。不要同时在其他地方监听同一声音并外放，以免重复收音。
5. 点击“开始翻译”，等状态显示收音已准备好再讲话或播放内容。

首次运行或更新后，macOS 可能再次要求语音、麦克风、屏幕与系统音频权限。请按系统提示授权；缺少权限时，旧文字仍可显示，但不能据此判断正在正常收音。

## 人名、专业词与前文

“设置 → 术语与前文”每行填一条，例如：

```text
Jensen Huang = 黄仁勋
Project Aurora = 晨光计划
retrieval-augmented generation = 检索增强生成
```

点击“保存术语表”。翻译使用完整术语表中的相关词；识别使用最多前 100 个简短、不重复的源语言词组。建议录音前保存；正在录音时修改也会更新请求配置，下一次识别请求一定采用新配置。提示不是强制替换，识别结果仍可能听错。

“本场名单”用于当前会议的人名、公司、产品和专业词，格式与通用术语表相同，填写后点“保存本场名单”。同名词优先采用本场写法；识别提示优先考虑本场名单和明确记住的纠正，再考虑通用术语，仍受 100 个简短词组的限制。开启历史记录时，重开会保留本场名单；清空内容开始新场次后不沿用。

“参考前面说过的话”帮助理解“他”“这个项目”等指代。只参考本场前面的原文与已完成译文；开启后这些内容也会发给所选服务。

## 听错后修改

点击某一段旁的“修改原文”，改好后点“保存并更新译文”。这段会重新翻译并标为“已手动修改”；后续自动识别不会覆盖它。其他段继续识别、翻译。重开应用后修改仍保留。

只改一个简短人名或专业词时，编辑框可能显示“记住人名或术语纠正”。勾选后保存，以后会辅助识别，并在听到同样写法时提供“采用这次纠正并更新译文”建议；只有点击采用才会改原文。它不会悄悄替换听写，也不会覆盖已手动修改的段落。数字、金额和单位的修改不会存成通用替换规则。可在设置的纠错记忆列表逐项忘记；删除历史不会同时删除主动保存的通用术语和纠错记忆。

编辑框内空格正常输入；Esc 取消这次编辑。主界面的 Esc 停止录音，空格可完成当前一段翻译。

## 数字、金额、日期与单位

含这些内容的段落会提醒核对听写原文。应用会检查译文是否遗漏、改变或额外补出数字、日期、单位、币种以及名单中的人名和术语；发现疑点后会去掉前文再试一次，仍有疑点就显示待核对，保留原文，不把可疑译文当成完成。额外尝试仍使用所选服务，可能增加少量调用费用。

检查只能对照已经听写出的文字，不能证明原话听对了，也不能覆盖所有表达方式。例如原话 fifty 被听成 fifteen，仍需你核对和修改；未说明币种的金额不应补成美元。待核对的内容重开后不会自动反复尝试。检查原文后修改并保存，或主动重试；导出时仍未解决的段落会标为待核对。

## 讲话快、回复慢或失败

应用最多同时翻译两段。后面的译文可能先完成，但每一段仍放在对应原文下，整场显示保持讲话顺序。顶部“待译 N 段”包括正在处理和等待补译的内容。

临时网络错误会自动重试；遇到限流会等服务要求的时间。仍未成功的段落可用“补译未完成内容”重试。不要因为某段还没译完就清空原文。服务整体变慢时仍会产生等待，应用不会通过丢句来掩盖。

## 耳机切换与暂时断连

麦克风模式跟随 macOS 当前选择的输入设备。在系统“声效”设置里切换耳机或内置麦克风；耳机断开时，由 macOS 决定可用输入。暂时收不到声音时，应用显示恢复状态并继续尝试，设备接回后会重新连接，不必反复点击开始。

“收音已准备好”表示已收到声音数据，不代表已经识别出文字。耳机可能自动切到手机；如一直没声音，先确认它已接回这台 Mac，并在系统输入列表中选对麦克风。点击停止后，后续设备变化不会自行开始录音。系统音频故障仍不会切到麦克风。姓名、数字和专业词仍需核对。

## 停止、恢复与历史

停止录音后，已收到的内容仍会继续翻译。开启历史记录时，整场文字自动保存。退出重开会恢复内容并补译未完成的段落，不会自动开始录音。

“清空”用于结束当前场次并开始新场次，已保存内容仍可从历史记录查看。关闭保存历史不会删除旧记录。删除单条历史会同步删除整场保存中的对应内容；“清空所有历史记录”也会清空当前窗口。已导出的文件需另行删除。请定期管理本机历史；保存出错时先保留窗口，不要清空。

## 导出与隐私

“导出本次”可查看、复制或保存本场文字。先等待译数量归零，再导出完整版本。导出前检查人名、数字和临时改口。参阅[隐私说明](../../PRIVACY.md)，勿把真实会议或密钥用于公开问题反馈。

# 测试说明

## 无真实凭据的自动检查

```bash
python3 scripts/check_public_source.py
bash scripts/test.sh
```

需要完整 Xcode 和 macOS。脚本可从任意工作目录调用；默认结果目录为 `build-local/tests/<时间>/`，构建缓存为 `build-local/DerivedData/`，不提交这些文件。

可用 `VOICE_TEST_RESULTS` 和 `VOICE_DERIVED_DATA` 指定路径，也可把 Xcode 参数传给脚本：

```bash
bash scripts/test.sh -only-testing:VoiceTranslationTests/RecognitionHintsAndCatchUpTests
```

默认测试使用隔离设置和模拟回复，不需要真实 API 密钥，不调用计费接口。项目中存在历史测试文件，只有 Xcode 工程登记的文件会运行；请以实际结果中的用例列表为准，不把磁盘文件数当成测试覆盖率。新增用例必须登记到工程或写入已登记的测试文件。

重点覆盖：短回复、识别修订、自然分段、手动编辑优先、失败重试、历史恢复、术语提示、最多两路翻译、单段变慢时后文推进、限流等待、密钥迁移成功/失败。

真实服务用例默认跳过，不能把跳过项算成通过。真实服务验收只在显式提供私有配置时运行（`VOICE_LIVE_CONFIG`，或本机临时文件 `/tmp/voice-live-acceptance.json`）；配置含 endpoint、model、apiKey，可选 report。配置文件仅当前用户可读，验收后移除，不得提交。该用例延迟一段真实请求来验证后文推进，不验证麦克风、系统音频或蓝牙硬件。

## 实际设备验收

请使用虚构人名和金额，并记下版本、输入来源、每段原文与译文、等待时间及失败情况。

- 麦克风：说短回答、人名、数字、长句和临时改口，确认新的声音产生新的原文和译文。
- 系统音频：播放代表性语音，确认正常及静音时都可捕获；切换后确认来源正确。
- 术语：同一段音频在不使用/使用术语时各跑一次，记录实际识别结果，不以配置成功替代效果验证。
- 快速连续讲话：检查所有内容保留、顺序不变，停止讲话后待译数量归零。
- 临时慢回复：用仅绑定本机的测试服务延迟一段回复，检查其他段仍推进、慢段最终补齐；另测服务整体限流后的恢复。
- 编辑与恢复：在翻译过程中修改原文，继续讲话并退出重开，检查修改和对应译文保留。
- 设备恢复：实际断开耳机再连接；实际睡眠再唤醒，必须验证恢复后的新声音，不能只看状态文字。

不在无人看护时强制系统睡眠、改变网络或操作他人会议。测试必须恢复音量、输出设备和服务地址。不要上传测试中产生的真实数据或凭据。

## 公开源码检查的范围

`check_public_source.py` 检查当前可提交文件中的明显密钥、内置服务凭据和误入的本机构建产物。它不覆盖所有编码方式、已删除文件和完整 Git 历史，不能替代发布前审阅。故意构造的测试凭据应明确带 `test` 前缀。

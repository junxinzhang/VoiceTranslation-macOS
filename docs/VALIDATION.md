日期：2026-11-15。录音与翻译逻辑已在实际 Mac 上验证；为公开仓库整理时，只更新了项目地址、说明和不属于应用的旧宣传页面，未改动录音与翻译逻辑。

| 检查 | 结果 |
| --- | --- |
| 麦克风实际收音与翻译 | 约 55 秒的人名、专业词与连续快讲样本，9 段全部译完，播放结束约 2 秒补齐 |
| 静音下的系统音频 | 约 49 秒的新样本，10 段全部译完，约 2 秒补齐，最多 2 段待译；新编号 8642 正确识别 |
| 首次导出及文件保存 | 10 组原文与译文逐条核对一致 |
| 退出重开 | 整场内容、语言方向和手动修改保留，录音不自动启动 |
| 自动检查 | 138 项通过，0 失败；1 项需要手动开启的真实服务检查默认跳过 |
| 单独的真实服务慢回复检查 | 第一条延迟 10 秒，后面 3 条先完成，4 条约 14.4 秒全部完成；输入为文字样例 |
| 公开源码检查 | 无内置服务密钥，检查脚本的 4 个样例通过 |

测试样本为合成语音，经扬声器由麦克风实际收音，或由系统音频捕获。数字是当时这台 Mac 和所选服务的结果，不是所有设备、网络或服务的性能承诺。少见词仍可能听错，例如 Kubernetes 在部分样本中被误识别。

早期版本曾单独测试较长时间录音、耳机断连和睡眠唤醒；这些结果不作为当前公开快照的全平台兼容性保证。尚未完成 Intel 实机和所有最低系统版本的实测。

仓库的 [自动构建检查](https://github.com/junxinzhang/VoiceTranslation-macOS/actions/workflows/build-macos.yml) 不使用真实服务密钥。它不能代替麦克风、系统音频、蓝牙和睡眠恢复的实际设备测试。

## 发布范围

本次只公开源码。默认构建使用临时签名，没有经过 Apple 公证。正式分发安装包前，请完成自己的 Developer ID 签名、公证和相应设备验证。不要关闭系统安全保护来绕过安装警告。

请勿在问题反馈中上传真实对话、密钥、本机设置或个人资料；使用虚构样例复现即可。

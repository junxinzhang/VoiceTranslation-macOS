# 🎬 翻译悬浮窗 — 完整设计规格书

> **项目**: Voice Real-time Translation
> **功能**: 翻译内容悬浮窗（看视频时使用）
> **日期**: 2026-02-26
> **状态**: 设计完成（截图在聊天记录中）

## 一、功能入口

在主界面底部栏的「历史」按钮**左侧**新增一个绿色高亮的「悬浮窗」按钮：

- **图标**: `picture-in-picture-2`（Lucide 图标库）
- **文案**: 悬浮窗
- **样式**: 绿色文字 #3D8A5A + 浅绿背景 #3D8A5A15 + 绿色边框 #3D8A5A40
- **字体**: Outfit 13px weight 500
- **圆角**: 8px
- **内边距**: [8, 12]
- **Home 页和 Recording 页都需要显示此入口**

- 标题: 「翻译服务连接失败」16px weight 600
- 描述: 「请检查网络连接或 API 配置后重试」13px
- 重连按钮: 红色 `#E54D42`，圆角 20px，图标 refresh-cw + 文案「重新连接」

## 五、设计决策说明

### 为什么用深色半透明背景？
悬浮窗需要浮在视频画面上方，深色半透明 `#1A1918F2` + `background_blur` 可以：
1. 保证字幕在**任何视频画面上**都清晰可读
2. 不过度遮挡视频内容
3. 与现有 App 的深色元素保持视觉一致

### 配色一致性
- 空闲绿 `#3D8A5A` = 主 App 的「就绪」状态
- 识别橙 `#D08068` = 主 App 的「录音中」状态
- 错误红 `#E54D42` = 语义通用错误色
- 字体统一使用 `Outfit`

### 为什么原文 + 译文双行？
- 看视频时主要看**译文**（大字号），原文做参考
- 原文用低对比度灰色，不抢视觉注意力
- 可以切换为"仅译文"模式进一步精简
